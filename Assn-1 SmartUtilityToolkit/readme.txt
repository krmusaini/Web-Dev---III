Smart Utility Toolkit

This assignment is a hands-on Node.js project that demonstrates backend fundamentals using Node.js core modules. 
It includes a CLI-based calculator, a reusable custom module, a basic HTTP server with multiple routes, a file manager for CRUD operations, and a random dice generator using the crypto module. 
The project also demonstrates command-line arguments, file handling, HTTP requests, modular programming, console-based debugging, and asynchronous execution. 
No external npm packages or frameworks are used.

Technologies: Node.js, JavaScript, process, http, fs, crypto modules.
